# Haunted House

A 3D haunted house built with React Three Fiber, following Bruno Simon's Three.js Journey tutorial.

## About

This project is a learning exercise to explore Three.js through React Three Fiber.

The scene is built progressively, starting with basic geometries and moving on to textures, lighting, shadows, and atmosphere.

## Built With

- React
- TypeScript
- Three.js
- React Three Fiber
- React Three Drei

## Getting Started

Clone the repository:

```bash
git clone https://github.com/decaudin/haunted-house.git
```

Navigate to the project directory:

```bash
cd haunted-house
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
